         frame AE generation, exposure bounds, user EV, AE balance, base ISO, focal value,
         and optional request-tagged ISO

  stale frame: reject when frame AE generation != current solver generation
  update floor: 16 ms; first dt: 1/30 s
  startup interval: 1.5 s; target history: 300 ms
  target tau: 0.025 s startup / 0.100 s steady
  correction tau: 0.050 s startup / 0.100 s steady
  movement rate: 12 EV/s startup / 4 EV/s steady, max 0.20 EV per update
  deadband: 0.025 EV startup / 0.040 EV steady

  AE balance clamp: -1.5 EV to +3.0 EV
  AUTO allocation uses base ISO, focal-dependent shutter pivot, feasible ISO/shutter bounds,
  and the same bounded per-frame component movement.
  ISO_PRIORITY collapses ISO bounds; SHUTTER_PRIORITY collapses shutter bounds; MANUAL disables AE.
