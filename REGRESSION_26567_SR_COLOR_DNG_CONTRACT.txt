26567 permanent SR / JPEG color / DNG contract

SUPER RES OWNERSHIP
- Native Sabre Resolve + current VGN is the only authoritative RGB/chroma/highlight owner for the 50MP JPEG derivative.
- Direct-CFA true2x evidence may contribute only one bounded scalar luminance-detail factor applied equally to R/G/B.
- Direct-CFA true2x RGB ratios never become final JPEG color.
- phase support is genuinely 0/1/2/3/4; zero is never coerced upward.
- accepted phase support requires Sabre rejection acceptance plus source CFA below near-clip threshold.
- unsafe support, <=1 phase, shadows, clipped/near-clipped highlights, chroma disagreement or guide disagreement drive the residual toward exactly 1x Sabre color.
- SR-on publication keeps exact physical 2x dimensions and cannot silently fall back to 12MP.

SUPER RES SPEED
- Native Sabre still uses the complete accepted NORMAL burst for temporal denoise/color.
- JPEG-only true2x reconstruction retains at most the strongest evidence frame in each of four subpixel phase bins.
- The redundant second full-50MP MGC denoise pass is disabled because native Sabre/VGN already owns finished RGB.
- If a normal stacked SR DNG is requested, the JPEG phase cap is disabled and the complete 26566 NORMAL evidence population is reconstructed, preserving the 26566 DNG SR behavior.

DNG HARD INVARIANT
- dedicated DNG writers are byte-identical to successful 26566.
- ImageSaver is byte-identical to successful 26566.
- native/vendor dependencies are byte-identical.
- source-clipping changes only phase-support eligibility; it never gates RGB accumulation used by the pristine pre-VGN true2x DNG carrier.
- DNG color, metadata, processing, publication and Super Res behavior remain unchanged.

JPEG COLOR OWNERSHIP
- 26566 Iris Camera2/DNG JPEG solver remains base camera characterization owner.
- solver additionally maps ProPhoto working profile into linear Display-P3 before JPEG appearance/tone/gamut rendering.
- normal Photo, Motion, Night and Super Res use the shared Iris JPEG owner.
- valid calibrated HueSat profile data is used when present; universal appearance is used when calibrated HueSat data is absent/invalid.
- legacy CCT cube/matrix authority cannot override the valid Iris JPEG solver.
- universal color preserves the neutral axis, is highlight/shadow/gamut protected, and is hue-direction preserving rather than a blanket saturation scalar.
- post-color luminance consumers use Display-P3 luminance coefficients.
- bitmap/native publication detects already-P3 pixels and does not apply sRGB->P3 twice.
- Jin keeps its proven sRGB model input/output contract through an sRGB inference copy and a P3 boundary residual adapter.
- UHDR base/gain ownership remains shared with the same P3 base; no duplicate color transform is allowed.
