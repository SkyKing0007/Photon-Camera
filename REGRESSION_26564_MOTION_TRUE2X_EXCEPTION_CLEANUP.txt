IRIS 26564 PERMANENT REGRESSION — MOTION TRUE2X EXCEPTION CLEANUP

Failure found during candidate audit:
After PhotonMotionMgc1271Bridge transferred true-2x disk carriers into HdrxProcessor,
exceptions before the normal RAW/JPEG cleanup sites could orphan those files because the
paths were local to ApplyHdrX() and Run() finally could not see them.

Permanent conditions:
1. HdrxProcessor retains processor-level cleanup references immediately after bridge handoff.
2. Run() finally deleteIfExists both references on all non-transferred paths.
3. Normal success/raw-only/no-DNG deletion clears the corresponding processor reference.
4. Deferred DNG clears the processor linear reference only after the executor closure has
   captured its own immutable path; the executor finally owns deletion thereafter.
5. Regression fails if bridge handoff can be followed by an exception with neither processor
   finally ownership nor deferred-output ownership.
