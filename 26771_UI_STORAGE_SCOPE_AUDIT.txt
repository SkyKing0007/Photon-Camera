26771 UI / ORIENTATION / STORAGE OWNERSHIP AUDIT
Runtime authority: exact successful 26770 compiled candidate.
No source was written until the read-only owner audit identified the active paths below.

LAUNCH / SPLASH
- Active branded launch owner was SplashActivity registered as MAIN/LAUNCHER with Theme.Photon.Splash and splash_background.
- 26771 unregisters the custom SplashActivity launch owner and makes CameraActivity the direct portrait launcher.
- API 31+ system splash is reduced to black/transparent/0-duration presentation; Android's system launch transition itself is not bypassed.

PHYSICAL ORIENTATION
- CustomOrientationEventListener already drove UI rotation but returned immediately when Android ACCELEROMETER_ROTATION was disabled.
- 26771 removes only that dependency; CameraActivity itself remains portrait-locked.
- Ordinary rotating controls keep existing bindRotate ownership.
- Front-camera physical rotation belongs to camera_switch_container; flip_camera_button keeps its existing independent rotationBy(180) tap animation.
- format_selector_pill and the mode switcher remain fixed.
- iris_live_histogram and spektra_live_histogram use a dedicated measured-size safe-pivot binding: -90 hangs down from bottom-right; +90 hangs down from bottom-left; this prevents center rotation into the timer/flash/settings area.
- all lens labels use one common 9sp size inside the existing invisible circular button bounds, including long live zoom labels such as 123.8x.

STORAGE OWNERSHIP
- Previous active picker used a DCIM initial path and SimpleStorageHelper contained DCIM/PhotonCamera assumptions.
- Previous FileManager.CreateFolders() was the Photon directory creator.
- 26771 uses OpenFolderPickerContract with no forced initial path and persists the exact user-selected SAF tree.
- The selected tree owns Iris Camera/Tuning, Iris Camera/Spektra, and Iris Camera/Raw.
- FileManager Photon-named fields survive only as compatibility aliases; CreateFolders() is removed.
- system DCIM/Camera remains independent and unchanged.
- stale runtime DCIM/PhotonCamera literals are forbidden.
- tuning/config/customCCT/settings/Spektra/RAW/DNG transports are routed to the selected Iris root where required.

LOGGING
- Existing Iris Log.java and MotionTrace.java are byte-protected unchanged.
- Current independent MediaStore/Downloads logging ownership/location remains unchanged; 26771 does not force logs through SAF.

PROTECTED CAMERA DOMAINS
- successful 26770 CaptureController, VGN postprocessor, MotionV2 tone/render/gainmap shaders, full 271 asset-shader universe, Sabre/Plan-B/Super-Res/alignment/exposure/UHDR color/tone owners remain protected except storage transport call sites explicitly listed in the runtime allowlist.
