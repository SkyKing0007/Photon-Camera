Permanent device-runtime regression: requested Super Res silently saved native-resolution JPEG

Observed lineage: successful 26565 V1.2 device A/B capture, 2026-08-30.
SR-off shot: native-resolution path.
SR-on shot: long true2x/Sabre processing, yet final JPEG remained about 12 MP.
Historical log also recorded IRIS_26564_MOTION_TRUE2X_JPEG_DEGRADED_TO_NATIVE reason=true2x_encoder_failed.

Root ownership defects carried into 26565:
1. native true2x RGB8/gain raw scratch paths were derived from final DCIM JPEG/gain paths;
2. native boolean combined successful 50MP base encoding with auxiliary gain encoding;
3. ImageSaver explicitly replaced any false true2x result with the ordinary native-resolution JPEG.

Permanent 26566 conditions:
- raw/non-media true2x scratch is based on the private RGB16F carrier path, never DCIM output path;
- a successfully encoded 50MP base returns base success even if auxiliary gain encode fails;
- Java promotes the exact 50MP P3 base to SDR if gain/JPEG-R packaging fails;
- SR-on failure cannot call MotionV2Jpeg444Encoder.write(native bitmap);
- final JPEG dimensions are read from the encoded JPEG and must equal exactly 2x bitmap width/height;
- for a full 4096x3072 source rotated 90 degrees, accepted result is 6144x8192 = 50,331,648 pixels;
- no successful SR-on path may silently produce 12 MP.
