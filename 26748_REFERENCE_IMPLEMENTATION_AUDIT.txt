- 26747 barcode/text/neutral-edge samples show cyan/magenta/rainbow separation outside clipped highlights; one supplied capture had clippedFraction=0.0.
- Exact 26747 Wronski merge computes each aligned NORMAL observation's RGB estimate before temporal collapse, but publishes only accumulated RGB/channel-validity support to VGN.
- Existing physicalColorTrust proves valid/unclipped source support, not cross-observation hue agreement.
- 26729+ material color gates can therefore protect coherent false reconstructed chroma after it is created.
- 26737 post-RGB CFA alias heuristic is not restored. ResolveSabre/second demosaic is not restored.

- NORMAL observations only; LONG/SHORT excluded.
- No modification of frameWeight, RGB numerators/weights, rejection, HDR, DNG, luma/detail, tone, or native true2x publication.
- VGN derives raw temporal coherence |E[C]|^2/E[|C|^2] plus direction agreement with current reconstructed chroma.
- If evidence is insufficient, behavior fails preserve to 26747.
- When reliable RAW observations do not support the final chroma direction, only post-26729 color-protection permission is reduced; existing cleanup remains the owner.
- 26747 full 26727 0.72..0.92 unrecoverable-highlight authority is retained unchanged.
