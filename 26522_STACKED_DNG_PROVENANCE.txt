26522 CHANGES — STACKED DNG ONLY
1) FULL-PRECISION SYNTHETIC DNG DOMAIN
   - Keep MGC's already normalized, black-subtracted Bayer16 result directly.
   - Remove the 26520/26521 conversion that rounded the fused result back to the source sensor's
     integer code lattice.
   - Stacked-DNG-only writer advertises BitsPerSample=16, BlackLevel=0, WhiteLevel=65535.
   - Ordinary single-frame RAW still uses the device Camera2 black/white contract unchanged.

2) PORTABLE METADATA CONTRACT
   - No Xiaomi/10-bit source constants are introduced.
   - Source sensors may report different black/white levels; MGC normalizes each frame using those
     device values before the synthetic DNG domain is created.

3) STACKED DNG NOISEPROFILE
   - Android Camera2 SENSOR_NOISE_PROFILE is defined for signal normalized to [0,1].
   - Use the reference Camera2 profile when available, otherwise the already selected valid MGC
     noise model.
   - Divide the normalized per-frame profile by the measured harmonic effective support so the DNG
     no longer inherits stale one-frame/slider-count noise metadata.
   - DNG NoiseProfile is global by specification, while local support remains spatially varying;
     the harmonic support is used as the variance-equivalent global summary.

4) TRUE NORMAL-ONLY EFFECTIVE SUPPORT
   - The existing Bayer merge accumulator's unused B channel stores each NORMAL frame's squared
     contribution weight (scaled by 1/256) while the existing G channel remains sum(weight).
   - Effective support is N_eff=(sum w)^2/sum(w^2).
   - A small 128-long-edge support sampling pass reports min, p01, p10, median, mean, max, and the
     harmonic/noise-equivalent support.
   - No second RAW alignment/rejection pass is added.
   - Short/Bento/Long remain excluded from the DNG support population.
