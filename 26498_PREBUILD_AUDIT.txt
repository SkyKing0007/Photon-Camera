True-photo border root correction

- Every physical output pixel is therefore >=12 samples inside the RCD computational band.
- No clamped RCD edge kernel and no PPG/RCD algorithm switch is active.

Colored-wall root localization

- Explicit stages: fused Bayer, post-RCD, post-display exposure, post-Camera2 color transform, post-render.

UHDR root correction

- 26498 emits one 8-bit gain value per primary SDR pixel (full-resolution R8 gain map).
- Android Ultra HDR v1 allows gain-map resolution to be implementation-defined, including the same resolution as the primary image.
- A same-resolution gain map removes the quarter-resolution gain-map spatial resampling that was measurably softening the UHDR rendition.
- SDR remains the full-resolution primary image; UHDR applies standard per-pixel logarithmic gain metadata.
