26503 V2 — A-G math/regression audit
Date: 2026-08-18

A — FROZEN CAPTURE SCENE-KEY GLOBAL EXPOSURE
- Keep one large display-exposure owner. sensorDomainGain remains 1.0.
- Do not feed rendering decisions back into live Camera2/HAL AE.
- Scene key is derived from the selected reference frame's actual shutter/ISO/aperture (frozen shutter-time CaptureResult).
- EV100 = log2(N^2/t) - log2(ISO/100).
- Very-low-EV scenes use much lower p50/p90 display targets so real darkness remains dark.
- Normally exposed scenes converge back to the proven 26502 p50/p90 targets.
- Bright high-EV + shadow-dominated scenes get an additional global over-lift veto so a dark car cabin does not force the sky/window several stops brighter.
- Existing near-clip occupancy logic remains a one-way veto that can only REDUCE gain.
Synthetic checks:
  * extreme-dark representative: predicted global gain is about 2.2x, not 16x
  * ID5 representative: about 1.0-1.35x, not 4.7x
  * normal-scene target continuity preserved
  * high-EV shadow-dominated gain is <60% of old histogram-only request in the stress case

B — SHADOWS BEHAVE LIKE SHADOWS
- Global exposure is no longer the shadow-rescue mechanism.
- Local shadow recovery works in sensor-linear evidence space.
- Below the proven floor: exactly no lift.
- Midtones/highlights: exactly no local shadow lift.
- Maximum local shadow scale is 1.10x.
- Scale is scalar RGB, preserving hue ratios.

C — EXTENDED-RANGE HIGHLIGHT / GAMUT HANDOFF
- Camera2 color matrix remains byte-identical to tested 26502.
- Remove downstream neutral-white painting for recoverable extended-range RGB.
- Final display-gamut fit is a uniform peak scale when a color is outside display range, preserving RGB ratios/hue rather than clipping channels or mixing toward neutral white.
- True upstream exhausted neutral white remains neutral.
Synthetic check: warm highlight RGB ratios survive the gamut fit; neutral stays neutral.

D — BOUNDARY-ANCHORED SHORT-A OBSERVABILITY
- 26502 Tier-1 radius-2 correspondence remains first and final whenever it has enough observable evidence.
- Tier-2 is allowed only when Tier-1 has insufficient observable, unsaturated support — never to override a measured mismatch/ambiguity.
- Tier-2 validates the existing Wronski prediction using sparse farther-out boundary evidence; it does not invent unrestricted motion.
- Strong conflicts, wrong flow, one-sided evidence, motion/object boundaries, and bad radiometry reject.
- Per-phase R/G1/G2/B authority remains independent; only SHORT_VALIDATED physical phases can contribute.
Synthetic checks: broad clipped stationary interior can recover; wrong flow/motion/color edge/one-sided evidence fail; phase isolation retained.

E — PIXEL-LOCAL EFFECTIVE STACK PERMISSION
- Existing currentDirectFrameSupport is the authoritative full-resolution frame-equivalent support carrier.
- Normalizer RGB math remains unchanged; alpha carries local support only.
- MotionV2DisplayExposure consumes alpha once before the later vec3 graph drops it.
- Local shadow opening is reduced in a 3.37-effective-frame region relative to a 14-frame region even if the requested burst count is 15.

F — BOTTOM-BORDER CHROMA PROOF GATE
- The reference/auxiliary border support-count asymmetry was audited.
- Different support COUNTS alone are algebraically unbiased after independent semantic normalization when accepted samples have the same physical color.
- Therefore 26503 does NOT add a speculative border desaturation, mask, blur, mirrored auxiliary fallback, or colored-band patch.
- E reduces amplification in weak local-support border regions.
- A future border reconstruction change requires direct proof of a physical edge-sampling bias, not just the existence of fewer auxiliary samples.
