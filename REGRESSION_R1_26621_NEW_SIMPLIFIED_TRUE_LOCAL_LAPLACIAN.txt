3. NO STALE 26620 LOCAL-TONE AUTHORITY

4. TRUE LOCAL-LAPLACIAN PRESENTATION CONTRACT
The local operator uses a seven-level Gaussian/Laplacian hierarchy, reference-sliced monotonic remap in log mapped luminance, triangular reference interpolation that partitions unity, matched REDUCE/EXPAND geometry, and reconstructs a full-resolution absolute log-tone target. 5. COLOR AND BLACK PROTECTION
Local presentation is applied as one common RGB scalar derived from the source guide and mapped guide. Exact black receives no offset; deep shadows fade to the shared global result. The local stage must not create an independent hue/saturation owner.

6. TRUE2X / UHDR PARITY
True2x CPU/GPU consume the same full-resolution local tone field and shared global equation. Existing successful-26620 UHDR gain/headroom, DNG, SHORT/CFA/Sabre/merge/VGN/denoise behavior remains protected outside the changed presentation domain.
