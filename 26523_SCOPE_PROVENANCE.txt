CORRECTED 26523 DNG DIAGNOSTIC
- 26522's reported ~4 effective frames was biased low because it squared each frame's already-summed
  Spatial kernel weight. A frame can contribute several same-CFA samples, so square(sum(weights))
  is not the output variance moment.
- 26523 leaves the tested Bayer signal/normalization channels R/G exactly unchanged.
- The unused diagnostic channels now carry the missing variance terms:
    B += frameWeight^2 * sum(individualSpatialKernelWeight^2)
    A = reference frame normalized-kernel variance (written once by the reference draw)
- The support pass combines those with the exact accumulated normalization weight to report
  reference-frame-equivalent N_eff. It equals 1 for the reference alone and approaches the number
  of equally useful frames when their kernels/noise are comparable; it is clamped to admitted
  NORMAL frame count.
- This is much closer to the user's actual question — how much random-noise reduction the DNG merge
  has relative to one reference frame — while still retaining per-pixel motion/rejection weighting.
- The global DNG NoiseProfile uses the harmonic reference-frame-equivalent support. The NORMAL burst
  is equal-exposure, and the metric is deliberately capped so metadata cannot claim more frame
  reduction than the admitted population.
- No merge/rejection threshold or JPEG/UHDR reconstruction equation is changed.

TOUCH FOCUS
- Focus events are accepted only when the touch is inside the actual rendered GLPreview rectangle;
  black UI regions no longer create a focus point.
- Metering authority is SENSOR_INFO_ACTIVE_ARRAY_SIZE / pre-correction active array when required,
  plus the current SCALER_CROP_REGION. SENSOR_INFO_PIXEL_ARRAY_SIZE is retained only as a defensive
  fallback for a broken HAL that omits active-array metadata; it is no longer the primary mapping.
- Additional center crop matches the visible preview aspect ratio before tap coordinates are mapped.
- Metering rectangle bounds are clamped correctly; the historical x/y edge typo is removed.
- Normal tap: touch focus using the existing AF/AE region behavior.
- Long press: real Camera2 AF_TRIGGER_START lock; no manual LENS_FOCUS_DISTANCE and no AE lock.
- While locked, the focus circle stays visible. A normal tap inside the viewfinder cancels the lock
  and restores normal autofocus. A subsequent tap can choose a new focus point.
- CaptureController preserves a user-requested long-press focus lock across a Motion capture and
  processing completion; it is not cleared by the ordinary post-capture unlockFocus routine.
