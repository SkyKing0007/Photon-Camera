Why 26525 exists
----------------
26524 correctly freezes Motion zoom at shutter and applies the same local zoom geometry
to the Motion JPEG/UHDR render, but the synthetic stacked Motion DNG still contains the
full stacked Bayer image with no DefaultCrop metadata. RAW editors therefore open a wider
composition than the Motion JPEG at digital zoom values.

26525 adds the standard DNG DefaultCropOrigin (tag 50719) and DefaultCropSize (tag 50720)
metadata to the synthetic normalized16 stacked Motion DNG only.

The DNG pixel array is NOT physically cropped, resized, resampled, demosaiced, sharpened,
or super-resolved. Full stacked Bayer data remains available in the DNG.

Crop authority
--------------
The crop uses the already-frozen 26524 shutter-time field:
    parameters.motionV2OutputZoom

This is the local zoom relative to the active optical camera. Therefore:
- exact optical anchor -> local zoom ~= 1.0 -> full DNG default crop
- digital zoom inside an optical interval -> centered default crop
- physical-lens handoff continues to be owned by the existing 26524 zoom architecture

Crop geometry
-------------
For zoom > 1:
- crop width/height = floor(full dimension / frozen local zoom)
- crop width/height are forced even
- centered origin is forced even
- origin and size are clamped inside the actual DNG dimensions

Even origin/size preserve the 2x2 Bayer phase.
At 1x the DefaultCrop is the full DNG dimensions.

DNG tag representation
----------------------
DefaultCropOrigin and DefaultCropSize are written as two TIFF LONG values each:
- Origin: H,V = X,Y
- Size: H,V = width,height

TinyDNG provenance
------------------
Photon currently downloads TinyDNG at native configure time. 26525 pins the header to:
repository: ParticlesDevs/tinydng
commit: 857590b3997818a4ccfbb8a42dd21c76273d6837
Git blob SHA-1: 624d614bf3e3bccb394ec54d1bca5bbb350859be

CMake verifies that exact upstream Git blob with `git hash-object` before applying a
small deterministic in-configure extension that adds:
- TIFFTAG_DEFAULT_CROP_ORIGIN = 50719
- TIFFTAG_DEFAULT_CROP_SIZE = 50720
- DNGImage::SetDefaultCrop(origin,size)

The extension follows TinyDNG's existing SetActiveArea/WriteTIFFTag TIFF_LONG pattern.

Temporal support / multi-frame SR decision
------------------------------------------
26525 deliberately does NOT retune temporal robustness and does NOT add multi-frame SR.

Corrected 26523 telemetry showed that all 15 NORMAL frames can be admitted while local
frame-equivalent support remains roughly 3-4. Current Spatial accumulation consumes the
upstream MGC robustness field as temporal weight. The exact upstream loss mechanism has
not yet been proven uniquely enough to justify weakening rejection.

The next temporal investigation should first decompose the active MGC robustness field.
Only after support loss is proven should rejection/weighting change. Multi-frame RAW/CFA
super-resolution should follow that work, reusing one alignment solution and preserving
CFA/color identity rather than upscaling demosaiced RGB.
